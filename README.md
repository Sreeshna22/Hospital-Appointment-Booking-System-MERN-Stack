# Hospital-Appointment-Booking-System-MERN-Stack

Hospital Appointment Booking System

Hospital Appointment Booking System is a user-friendly and efficient web application designed to streamline hospital appointment scheduling. Patients can easily book and manage appointments with doctors, while doctors and admins can track, update, and manage these appointments through a clean and secure interface. The system implements Role-Based Access Control (RBAC), ensuring secure access for patients, doctors, and admins.

🚀 Features
🧑‍💻 Admin

Manage Doctors – Add, update, or remove doctors from the system.

View All Appointments – Monitor all appointments in the hospital.

User Management – View registered patients and manage their access if needed.

🩺 Doctor

View Appointments – See a list of upcoming appointments.

Update Appointment Status – Change appointment status to Accepted, Completed, or Cancelled.



🧑‍🤝‍🧑 Patient

Register & Login – Secure authentication with role-based access.

Book Appointments – Schedule appointments with available doctors.

Cancel Appointments – Cancel upcoming appointments.

View Appointment History – Track past and upcoming appointments.



🛠️ Tech Stack

Frontend: React.js, Tailwind CSS, (Optional: TypeScript, React Query)
Backend: Node.js, Express.js, MongoDB, JWT Authentication, Socket.IO (optional for notifications)
Hosting: Frontend on Netlify, Backend/Full-stack on Render

🔮 Future Enhancements

Real-time Notifications – For appointment booking and status updates.

Doctor Availability Calendar – Display doctors’ available slots dynamically.

Advanced Analytics – Dashboard for admins to track appointments and doctor performance.

Multi-language Support – Make the app accessible in different languages.

Email/SMS Notifications – Notify patients of upcoming appointments.
